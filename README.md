## Selected work

**[finops-analyst](https://github.com/eeleeml/finops-analyst)** — Multi-agent
expense-audit system in Python. It reads invoices by vision, flags anomalies
against an expense policy, masks personal data and writes the report. An
orchestrator routes the request, a pipeline chains three specialist agents,
and the tools live in two MCP servers of my own. Built with Google ADK, Gemini
and FastMCP. The README documents the architecture, the design decisions and
the things that did not work.
